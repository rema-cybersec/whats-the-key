# What's The Key?
A simple collection of models for detecting key signatures of music.

# How to use?
Provide the model with a youtube link of the song with optional start and end time of the song and you will get an estimate.

# How to train?
I haven't included the trained weights because they were flawed. The models were mostly accurate, but because of the misslabeled data I chose to reserve that data. If you'd like to train it yourself you can do that by collecting the youtube link of the songs alongside it's key signature and optional start and end times.
